# CampusCart
MAD Final Proj

Student Campus Food Pre-Ordering
Background
CampusCart allows students to browse food items and place an order
before going to a campus food stall.
This is not intended to be a complete online food delivery system.
Students simply browse the menu, create an order, and monitor their
order status.

Required Functionalities
1. Registration/Login
Using Firebase Authentication.
2. Food Menu
Display:
• Food name
• Image
• Description
• Price
• Category
The food items can be pre-created in Firestore.
3. Food Details
Students can view the details of a food item.
4. Add to Cart
Students can:
• Select food
• Select quantity
• Add to cart
5. Order Summary
Display:
• Items
• Quantity
• Price
• Total
6. Place Order
Generate an order record in Firebase.
7. My Orders
Students can see their previous orders.
8. Order Status
Example:
• Pending
• Preparing
• Ready for Pickup
• Completed
These statuses can be simulated.
Firebase
• Authentication → student accounts
• Firestore → menu and orders
• Firebase Storage → food images
Device Features
Required:
• Gallery/photo picker → optional student profile photo
• Local notifications → order status notification
